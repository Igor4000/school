Adatbázis szerkesztés és létrehozás

Három önálló adatbázis-projekt, egyenként 15 könnyű lépéssel — kizárólag a program kezelőfelületén dolgozva.

#Megjegyzés: az Execute SQL fület egyik feladatban sem kell megnyitnod. Minden lépés a Database Structure és a Browse Data fülön történik. Minden projekt végén mentsd el a változtatásokat a Write Changes gombbal — enélkül a módosítások elvesznek.
📁 konyvtar.db — Iskolai könyvtár

Egy könyvtári nyilvántartás felépítése és karbantartása a nulláról.

01
LÉTREHOZÁSNew Database

Hozz létre egy új adatbázist a New Database gombbal, és mentsd el konyvtar.db néven.

02
LÉTREHOZÁSCreate Table

A Database Structure fülön hozz létre egy új táblát Konyvek néven.

03
LÉTREHOZÁSFields

Adj hozzá öt mezőt: id (INTEGER, Primary Key, AutoIncrement), cim (TEXT), szerzo (TEXT), kiadas_eve (INTEGER), ar (REAL).

04
SZERKEZETNot Null

Állítsd be, hogy a cim mező Not Null legyen, vagyis kötelező legyen kitölteni.

05
MENTÉSWrite Changes

Kattints a Write Changes gombra, hogy elmentsd a tábla szerkezetét.

06
MEGTEKINTÉSBrowse Data

Lépj a Browse Data fülre, és válaszd ki a Konyvek táblát a legördülő listából.

07
REKORDInsert new record

Az Insert new record gombbal vegyél fel öt könyvet saját adatokkal.

08
MÓDOSÍTÁSBrowse Data

Módosítsd az egyik könyv árát: kattints duplán a cellára, és írd be az új értéket.

09
TÖRLÉSDelete record

A Delete record gombbal törölj egy könyvet a listából.

10
SZERKEZETModify Table

Térj vissza a Database Structure fülre, és a Modify Table funkcióval adj hozzá egy új kategoria (TEXT) mezőt.

11
MÓDOSÍTÁSBrowse Data

Töltsd ki a kategória oszlopot minden könyvnél (pl. „Regény", „Tankönyv").

12
SZERKEZETDefault Value

A Modify Table ablakban állíts be alapértelmezett értéket a kategória mezőnek: Ismeretlen.

13
SZERKEZETRename Table

Nevezd át a Konyvek táblát Konyvallomany-ra a jobb klikk Rename Table opcióval.

14
REKORDBrowse Data

Vigyél fel kézzel egy új rekordot, amely egy meglévő könyv adatait ismétli meg, de a címéhez fűzd hozzá: „2. kiadás".

15
MENTÉSWrite Changes

Kattints a Write Changes gombra, hogy véglegesen elmentsd az adatbázist, majd zárd be a programot.

04

05
ČUVANJEWrite Changes

Klikni na Write Changes da sačuvaš strukturu tabele.

06
PRIKAZBrowse Data

07
ZAPISInsert new record

Pomoću Insert new record unesi pet knjiga sa sopstvenim podacima.

08
IZMENABrowse Data

Izmeni cenu jedne knjige dvoklikom na ćeliju i unosom nove vrednosti.

09
BRISANJEDelete record

Pomoću Delete record obriši jednu knjigu sa liste.

10
STRUKTURAModify Table

Pomoću Modify Table dodaj novo polje kategorija (TEXT).

11
IZMENABrowse Data

Popuni kolonu kategorija za svaku knjigu (npr. „Roman", „Udžbenik").

12
STRUKTURADefault Value

Podesi podrazumevanu vrednost za polje kategorija: Nepoznato.

13
STRUKTURARename Table

Preimenuj tabelu Knjige u Fond_knjiga desnim klikom i opcijom Rename Table.

14
ZAPISBrowse Data

15
ČUVANJEWrite Changes

Klikni na Write Changes da trajno sačuvaš bazu, a zatim zatvori program.
