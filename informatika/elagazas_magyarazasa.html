⚡ If-Elif-Else elágazásIf-Elif-Else grananje

Az elágazás (if) lehetővé teszi, hogy a program feltételektől függően más-más utasításokat hajtson végre. Pythonban az if, elif (else if) és else kulcsszavakkal építhetjük fel. Grananje (if) omogućava programu da u zavisnosti od uslova izvršava različite naredbe. U Pythonu se gradi pomoću ključnih reči if, elif (else if) i else.
✨ ALAP FELÉPÍTÉSOSNOVNA STRUKTURA ✨ if feltételuslov: utasításoknaredbe
elif másik_feltételdrugi_uslov: utasításoknaredbe
else: utasításoknaredbe

🧱 Az elágazás elemei (részletesen):🧱 Elementi grananja (detaljno):

  • if – kulcsszó, ezzel kezdődik az elágazás. Utána egy feltétel (logikai kifejezés).ključna reč, njome počinje grananje. Nakon nje sledi uslov (logički izraz).
  • feltételuslov – pl. szám > 0, nev == "Anna". Ha igaz, a hozzá tartozó blokk fut.npr. broj > 0, ime == "Ana". Ako je tačan, izvršava se pripadajući blok.
  • kettőspont :dvotačka : – minden feltétel után kötelező, utána behúzott blokk.obavezna je nakon svakog uslova, nakon nje sledi uvučeni blok.
  • elif – rövidítés: „else if". További feltételek ellenőrzésére, ha az előző IF hamis volt.skraćeno od „else if". Za proveru dodatnih uslova ako je prethodni IF bio netačan.
  • else – opcionális ág, ha egyik feltétel sem volt igaz, ez fut le.opciona grana, ako nijedan uslov nije tačan, izvršava se ova.

🧪 Hogyan működik lépésről lépésre?Kako radi korak po korak?

  1. A program először az if feltételét vizsgálja.Program prvo proverava uslov if.
  2. Ha az igaz, végrehajtja a hozzá tartozó blokkot, és kihagyja a többi ágat (elif, else).Ako je tačan, izvršava pripadajući blok i preskače ostale grane (elif, else).
  3. Ha az if hamis, akkor sorban ellenőrzi az elif ágakat (ha vannak).Ako je if netačan, redom proverava elif grane (ako postoje).
  4. Az első igaz feltételhez tartozó blokk fut le, a többi kimarad.Prvi tačan uslov izvršava svoj blok, ostali se preskaču.
  5. Ha egyik feltétel sem igaz, akkor az else ág (ha létezik) fut le.Ako nijedan uslov nije tačan, izvršava se else grana (ako postoji).

🎯 Összetett elágazások & trükkökSložena grananja & trikovi

Az if-elif-else mellett léteznek beágyazott elágazások, a terner operátor (egy soros if), valamint a logikai operátorok (and, or, not) kombinálása. Ezekkel még rugalmasabb feltételeket készíthetünk. Pored if-elif-else, postoje ugnježdena grananja, ternarni operator (if u jednom redu), kao i kombinovanje logičkih operatora (and, or, not). Pomoću njih možemo napraviti još fleksibilnije uslove.

⚠️ Gyakori hibák elágazásoknálČeste greške kod grananja

  • Egyenlőségvizsgálat:Provera jednakosti: if x = 5 (hibás!)(pogrešno!) helyettumesto if x == 5 (két egyenlőségjel kell).(potrebna su dva znaka jednakosti).

  • Elfelejtett kettőspont:Zaboravljena dvotačka: Minden if, elif, else után kell kettőspont.Nakon svakog if, elif, else mora ići dvotačka.
  • Több feltétel rossz sorrendje:Pogrešan redosled više uslova: Specifikusabb feltételek előrébb legyenek, különben a tágabb feltétel "lenyeli" az eseteket.Specifičniji uslovi treba da budu ispred, inače će opštiji uslov "progutati" slučajeve.
