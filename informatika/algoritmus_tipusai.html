    Bevezetés az algoritmusok világába

    Az algoritmusok a számítástechnika és a programozás alapvető építőkövei. Ismerjük meg, mik azok, mire használjuk őket, és milyen típusok léteznek.

    Mi az az algoritmus?

    Az algoritmus egy véges számú lépésből álló, jól definiált utasítások sorozata, amely egy adott probléma megoldására szolgál. Minden algoritmusnak tartalmaznia kell:

    Véges számú lépés

    Az algoritmusnak véges időn belül le kell futnia, nem futhat örökké.

    Egyértelműség

    Minden lépés pontos és egyértelmű legyen, ne jöjjenek létre félreértések.

    Bemenet

    Az algoritmus kaphat bemeneti adatokat, de ez nem kötelező.

    Kimenet

    Az algoritmusnak kell legyen kimenete, ami a probléma megoldása.

    Az algoritmusok története

    1. Szekvenciális (vonalas) algoritmusok

    A legegyszerűbb algoritmustípus, ahol az utasítások egymás után, sorrendben hajtódnak végre.

    Mi a szekvenciális algoritmus?

    A szekvenciális algoritmusok (vagy vonalas algoritmusok) egyszerű, lineáris utasítássorozatok. Az utasítások egymás után, a megadott sorrendben hajtódnak végre, minden utasítás egyszer fut le.

    Szekvenciális algoritmus szerkezete

    Kattints a diagram megtekintéséhez!

    { START }
    1. Lépés végrehajtása
    2. Lépés végrehajtása
    3. Lépés végrehajtása
    { END }
    Példák szekvenciális algoritmusokra

    Terület kiszámítása

    Egy egyszerű algoritmus a téglalap területének kiszámítására:

    # Téglalap területe / Površina pravougaonika def terulet_szamitas(a, b): # Szorzás / Množenje terulet = a * b # Eredmény visszaadása / Vraćanje rezultata return terulet # Használat / Upotreba: eredmeny = terulet_szamitas(5, 10) print("Terület:", eredmeny) # 50

    Adatfeldolgozás

    Egy felhasználó adatainak feldolgozása:

    # Felhasználó adatai / Podaci korisnika print("Kérem a nevét: / Unesite ime:") nev = input() print("Születési év: / Godina rođenja:") ev = int(input()) kor = 2026 - ev print("Köszönjük,", nev, "Ön / Vi imate", kor, "éves / godina.")

    2. Szelekciós (elágazásos) algoritmusok

    Az algoritmusok, amelyek feltételek alapján döntenek, és különböző utakat választanak a végrehajtás során.

    Mi a szelekciós algoritmus?

    A szelekciós algoritmusok (vagy elágazásos algoritmusok) tartalmaznak döntési pontokat, ahol a program futása a feltételek alapján elágazik. Ez lehetővé teszi, hogy az algoritmus különböző bemeneti adatokhoz különböző módon viselkedjen.

    Szelekciós algoritmus szerkezete

    Kattints a diagram megtekintéséhez!

    { START }
    Lépés 1 / Korak 1
    FELTÉTEL / USLOV ?
    IGAZ / TAČNO
    Lépés (igaz)
    HAMIS / NETAČNO
    Lépés (hamis)
    { END }
    Példák szelekciós algoritmusokra

    Két szám összehasonlítása

    Egy algoritmus, amely meghatározza a két szám közül a nagyobbat:

    def nagyobb_szam(a, b): if a > b: return a else: return b # Használat / Upotreba: eredmeny = nagyobb_szam(15, 8) print("Nagyobb / Veći:", eredmeny) # 15

    Értékelési rendszer

    Egy algoritmus, amely egy pontszám alapján osztályzatot ad:

    def osztalyzat(pontszam): if pontszam >= 90: return "Jeles (5) / Odličan (5)" elif pontszam >= 75: return "Jó (4) / Vrlo dobar (4)" elif pontszam >= 60: return "Közepes (3) / Dobar (3)" elif pontszam >= 40: return "Elégséges (2) / Dovoljan (2)" else: return "Elégtelen (1) / Nedovoljan (1)"
    Elágazások típusai

    Egyszerű elágazás

    Ha egy feltétel igaz, akkor végrehajt egy utasítást, különben nem csinál semmit.

    if uslov / feltetel: instrukcija / utasitas

    Kettős elágazás

    Ha a feltétel igaz, végrehajt egy utasítást, különben egy másikat.

    if uslov / feltetel: instrukcija1 / utasitas1 else: instrukcija2 / utasitas2

    Többszörös elágazás

    Több feltételt ellenőriz egymás után, és az első igaz feltételhez tartozó utasítást hajtja végre.

    if uslov1 / feltetel1: instrukcija1 elif uslov2 / feltetel2: instrukcija2 else: instrukcija3

    3. Iteratív (ciklusos) algoritmusok

    Az algoritmusok, amelyek egy utasításcsoportot ismételten végrehajtanak, amíg egy feltétel teljesül.

    Mi az iteratív algoritmus?

    Az iteratív algoritmusok (vagy ciklusos algoritmusok) ismétlődő utasításokat tartalmaznak. Ezek lehetővé teszik, hogy ugyanazt a kódrészt többször is végrehajtsuk anélkül, hogy többször leírnánk.

    Iteratív algoritmus szerkezete

    Kattints a diagram megtekintéséhez!

    { START }
    Inicializálás
    FELTÉTEL / USLOV ?
    IGAZ / TAČNO
    Ciklusmag
    Frissítés
    ↑ vissza / nazad ↑
    HAMIS / NETAČNO
    { END }
    Példák iteratív algoritmusokra

    Számok összege

    Egy algoritmus, amely összeadja az első N természetes számot:

    def osszeg_elso_n(n): osszeg = 0 i = 1 while i <= n: osszeg = osszeg + i i = i + 1 return osszeg # Használat / Upotreba: eredmeny = osszeg_elso_n(10) # 1+2+...+10 = 55 print("Összeg / Zbir:", eredmeny)

    Lineáris keresés

    Egy algoritmus, amely egy listában megkeresi egy érték első előfordulását:

    def linearis_kereses(lista, ertek): index = 0 while index < len(lista): if lista[index] == ertek: return index # Megtaláltuk / Pronađeno index = index + 1 return -1 # Nem találtuk / Nije pronađeno # Használat / Upotreba: szamok = [5, 12, 8, 3, 15] pozicio = linearis_kereses(szamok, 8) print("Pozíció / Pozicija:", pozicio) # 2
    Ciklustípusok

    Előtesztelő ciklus (while)

    Először ellenőrzi a feltételt, és csak akkor hajtja végre a ciklusmagot, ha az igaz.

    while uslov / feltetel: instrukcije / utasitasok

    Hátultesztelő ciklus (do-while)

    Először egyszer végrehajtja a ciklusmagot, majd ellenőrzi a feltételt.

    # Pythonban nincs beépített do-while # U Pythonu ne postoji ugrađeni do-while while True: instrukcije / utasitasok if not uslov / feltetel: break

    Számlálós ciklus (for)

    Egy változó értékét iterálja egy tartományon vagy egy gyűjtemény elemein.

    for i in range(pocetak, kraj, korak): instrukcije / utasitasok

    4. Rekurzív algoritmusok

    Az algoritmusok, amelyek önmagukat hívják meg egy kisebb problémára, amíg el nem érik az alapvető esetet.

    Mi a rekurzív algoritmus?

    A rekurzív algoritmusok olyan algoritmusok, amelyek egy problémát úgy oldanak meg, hogy azt kisebb, önmagához hasonló részproblémákra bontják, majd ezeket ugyanazzal az algoritmussal oldják meg.

    Faktoriális számítás

    A faktoriális függvény klasszikus példa a rekurzióra:

    def faktorialis(n): if n == 0: # Alapeset / Osnovni slučaj return 1 else: return n * faktorialis(n - 1) # Rekurzív hívás / Rekurzivni poziv # Használat / Upotreba: eredmeny = faktorialis(5) # 5! = 120 print("5! =", eredmeny)
    Rekurzió vs. Iteráció
    Rekurzív algoritmusok Iteratív algoritmusok
    Önmagukat hívják meg Ciklusokat használnak
    Általában rövidebb és elegánsabb kód Általában gyorsabbak és kevesebb memóriát használnak
    Könnyebb megérteni bizonyos problémáknál (pl. fa bejárás) Könnyebb hibakeresés
    Veszélyeztetheti a veremtúlcsordulást Nincs veremtúlcsordulás veszélye

    5. Algoritmusok összehasonlítása

    Az algoritmusok hatékonyságának értékelése és összehasonlítása különböző szempontok alapján.

    Hatékonysági szempontok

    Időbonyolultság

    Az algoritmus futási ideje a bemenet méretének függvényében. Jele: O(...)

    • O(1) – konstans idő
    • O(n) – lineáris idő
    • O(n²) – kvadratikus idő

    Tárbonyolultság

    Az algoritmus memóriahasználata a bemenet méretének függvényében.

    • O(1) – konstans tár
    • O(n) – lineáris tár
    • O(n²) – kvadratikus tár

    Prímszám ellenőrző algoritmus

    Készíts egy algoritmust, amely ellenőrzi, hogy egy adott szám prímszám-e! Az algoritmusnak tartalmaznia kell:

    • Szekvenciális részt (bemenet fogadása, eredmény kiírása)
    • Szelekciós részt (feltételek ellenőrzése)
    • Iteratív részt (oszthatóság vizsgálata)
    # Prímszám ellenőrző / Provera prostog broja def prim_e(n): if n <= 1: return False i = 2 while i * i <= n: if n % i == 0: return False i = i + 1 return True
