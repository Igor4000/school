1. Bevezetés a Pythonba

Mi az a Python és miért érdemes megtanulni?

Mi az a Python?

A Python egy magas szintű, általános célú programozási nyelv, amelyet Guido van Rossum hozott létre 1991-ben. A nyelv tervezési filozófiája a kód olvashatóságára és egyszerűségére helyezi a hangsúlyt.

A Python egyik legnagyobb előnye, hogy könnyen tanulható, ezért kiválóan alkalmas kezdők számára, de ugyanakkor hatékony és sokoldalú is, amit profik is szívesen használnak.

Python jelentése: A nyelv neve nem a kígyófajra utal, hanem a "Monty Python's Flying Circus" brit komédiasorozatról kapta a nevét.

A Python előnyei

  • Egyszerű szintaxis - könnyen olvasható és megérthető kód
  • Sokoldalú - webfejlesztés, adatelemzés, mesterséges intelligencia, stb.
  • Nagy közösség - rengeteg tananyag, könyv és segítség áll rendelkezésre
  • Ingyenes és nyílt forráskódú - bárki használhatja és módosíthatja
  • Platformfüggetlen - Windows, Mac, Linux rendszereken egyaránt fut

Az első Python program

A Pythonban a "Hello, World!" program nagyon egyszerű. Nézd meg az alábbi példát:

hello.py
# Az első Python programom
print("Hello, World!")
print("Üdvözöllek a Python tananyagban!")

A kód magyarázata:

  • A # karakterrel kezdődő sorok megjegyzések, amelyeket a Python figyelmen kívül hagy
  • A print() függvény a zárójelben megadott szöveget a képernyőre írja
  • A szöveget "idézőjelek" közé kell tenni
  • Minden utasítás új sorban van

2. Kiíratás a képernyőre

A print() függvény részletes bemutatása

A print() függvény

A print() függvény a Python egyik legalapvetőbb függvénye, amelynek segítségével információkat jeleníthetünk meg a képernyőn (konzolon).

Példák a print() használatára

print_peldak.py
# Egyszerű szöveg kiíratása
print("Ez egy egyszerű szöveg.")

# Szám kiíratása
print(42)
print(3.14)

# Több érték kiíratása egy sorban
print("A szám:", 100)

# Üres sor kiíratása
print()
print("Az üres sor után írok.")

A print() függvénynek több opcionális paramétere is van:

  • sep - az elválasztó karakter a kiírandó elemek között (alapértelmezett: szóköz)
  • end - a sor végén kiírandó karakter (alapértelmezett: új sor "\n")
print_parameterek.py
# sep paraméter - elválasztó karakter megadása
print("Python", "tananyag", "alapok", sep="-")
print("2023", "10", "15", sep=".")

# end paraméter - sor vége karakter megadása
print("Ez az első sor", end=" ")
print("de ugyanabban a sorban maradunk.")

# Több paraméter együtt
print("Első", "Második", "Harmadik", sep=" | ", end=" -> VÉGE")

3. Változók és adattípusok

Adatok tárolása és kezelése

Mi az a változó?

A változók olyan elnevezett tárolók a memóriában, amelyekben értékeket tárolhatunk. A változók lehetővé teszik, hogy ne kelljen mindig konkrét értékekkel dolgoznunk, hanem ezeket elnevezve hivatkozhassunk rájuk.

Változó létrehozása és használata

valtozok.py
# Változó létrehozása és értékadás
nev = "Anna"
kor = 16
magassag = 1.65
tanulo = True

# Változók értékeinek kiíratása
print("Név:", nev)
print("Kor:", kor)
print("Magasság:", magassag)
print("Tanuló:", tanulo)

# Változó értékének módosítása
kor = 17
print("Következő évben:", kor, "éves leszek")

Változónevek szabályai:

  • Betűvel vagy aláhúzással kell kezdődni
  • Tartalmazhat betűket, számokat és aláhúzásjeleket
  • Nem lehetnek benne szóközök
  • Különböző kis- és nagybetűk különböző változónevek
  • Ne használj Python kulcsszavakat (pl. print, if, for)

Alapvető adattípusok

Pythonban minden értéknek van típusa. Néhány alapvető adattípus:

adattipusok.py
# Szöveg (string) - szöveges adat
szoveg = "Python tananyag"
print("Szöveg:", szoveg, "| Típus:", type(szoveg))

# Egész szám (integer) - egész számok
egesz = 42
print("Egész szám:", egesz, "| Típus:", type(egesz))

# Valós szám (float) - tizedes tört
valos = 3.1415
print("Valós szám:", valos, "| Típus:", type(valos))

# Logikai (boolean) - igaz/hamis érték
igaz = True
hamis = False
print("Logikai értékek:", igaz, "és", hamis, "| Típus:", type(igaz))

A type() függvénnyel bármely változó vagy érték típusát lekérdezhetjük.

4. Felhasználói bevitel

A input() függvény és alkalmazása

A input() függvény

A input() függvény lehetővé teszi, hogy a felhasználó adatokat adjon meg a program futása közben. A függvény mindig szövegként (string) adja vissza a beírt értéket.

Alapvető input használat

input_alap.py
# Egyszerű input - üzenet nélkül
print("Kérlek, add meg a neved: ")
nev = input()
print("Üdvözöllek, " + nev + "!")

# Input üzenettel - a zárójelben megadhatjuk a felkérést
kor = input("Hány éves vagy? ")
print("Tehát " + kor + " éves vagy.")

# Több input egymás után
varos = input("Melyik városban laksz? ")
iskola = input("Melyik iskolába jársz? ")
print("Érdekes, te is " + varos + "-ban laksz és " + iskola + "-ba jársz!")

Típuskonverziók

Mivel az input() függvény mindig szöveget ad vissza, ha számokkal szeretnénk dolgozni, át kell alakítanunk a beírt értéket megfelelő típusra.

tipuskonverzio.py
# Számok bekérése - int() és float() függvények
szam_str = input("Adj meg egy egész számot: ")
szam = int(szam_str)  # Szöveg átalakítása egész számmá
print("A szám duplája:", szam * 2)

# Rövidített változat
szam2 = int(input("Adj meg egy másik egész számot: "))
print("A másik szám négyzete:", szam2 ** 2)

# Valós szám bekérése
tort = float(input("Adj meg egy tizedes törtet: "))
print("A tört fele:", tort / 2)

Figyelem: Ha a felhasználó nem számot ír be, de mi int() vagy float() függvénnyel próbáljuk átalakítani, a program hibát fog jelezni (ValueError).

5. Alapvető matematikai műveletek

Számokkal való műveletek Pythonban - részletes bemutatás

Aritmetikai operátorok

Pythonban számokkal különböző matematikai műveleteket végezhetünk. Az alapvető aritmetikai operátorok:

aritmetika.py
# Összeadás (+)
print("10 + 5 =", 10 + 5)

# Kivonás (-)
print("10 - 5 =", 10 - 5)

# Szorzás (*)
print("10 * 5 =", 10 * 5)

# Osztás (/) - mindig valós számot ad
print("10 / 3 =", 10 / 3)
print("10 / 5 =", 10 / 5)

# Egész osztás (//) - csak az egész rész
print("10 // 3 =", 10 // 3)

# Maradékos osztás (%) - az osztás maradéka
print("10 % 3 =", 10 % 3)
print("10 % 5 =", 10 % 5)

# Hatványozás (**)
print("2 ** 3 =", 2 ** 3)  # 2 a harmadikon
print("10 ** 2 =", 10 ** 2)  # 10 a négyzeten

Műveleti sorrend (precedencia):

  1. Zárójelek () - mindig először számoljuk ki
  2. Hatványozás **
  3. Szorzás *, Osztás /, //, % (balról jobbra)
  4. Összeadás +, Kivonás - (balról jobbra)

Használj zárójeleket, ha biztosra akarsz menni a sorrendben!

Feladat 5.3: Másodfokú egyenlet gyökeinek számítása Nehéz

Készíts egy programot, amely bekéri a másodfokú egyenlet együtthatóit (a, b, c), majd kiszámolja a diszkriminánst és a gyököket.

Képletek:

  • Diszkrimináns: D = b² - 4ac
  • Gyökök: x₁,₂ = (-b ± √D) / (2a)

Figyelj a negatív diszkriminánsra és a nullával való osztásra!

Példa megoldás
# Másodfokú egyenlet gyökeinek számítása: ax² + bx + c = 0
print("Másodfokú egyenlet gyökeinek számítása")
print("Az egyenlet alakja: ax² + bx + c = 0\n")

# Együtthatók bekérése
a = float(input("Add meg az 'a' együtthatót: "))
b = float(input("Add meg a 'b' együtthatót: "))
c = float(input("Add meg a 'c' együtthatót: "))

# Diszkrimináns számítása
D = b**2 - 4 * a * c

print("\nEredmények:")
print("Egyenlet:", a, "x² +", b, "x +", c, "= 0")
print("Diszkrimináns (D) =", round(D, 4))

# Gyökök számítása a diszkrimináns értéke alapján
if a == 0:
    print("Figyelem! Az 'a' értéke 0, ez nem másodfokú egyenlet.")
elif D > 0:
    # Két valós gyök
    x1 = (-b + D**0.5) / (2 * a)
    x2 = (-b - D**0.5) / (2 * a)
    print("Két valós gyök van:")
    print("x₁ =", round(x1, 4))
    print("x₂ =", round(x2, 4))
elif D == 0:
    # Egy valós gyök (dupla gyök)
    x = -b / (2 * a)
    print("Egy valós gyök van (dupla gyök):")
    print("x =", round(x, 4))
else:
    # Nincs valós gyök
    print("Nincs valós gyöke az egyenletnek.")
Feladat 5.4: Számtani sorozat összege Közepes

Készíts egy programot, amely bekéri egy számtani sorozat első elemét (a₁), differenciáját (d) és az elemek számát (n), majd kiszámítja az első n elem összegét.

Képlet: Sₙ = n/2 * [2a₁ + (n-1)d]

Példa megoldás
# Számtani sorozat összegének számítása
print("Számtani sorozat első n elemének összege")

# Adatok bekérése
a1 = float(input("Add meg a sorozat első elemét (a₁): "))
d = float(input("Add meg a differenciát (d): "))
n = int(input("Hány elemet szeretnél összeadni? (n): "))

# Ellenőrzés
if n <= 0:
    print("Hiba: n-nek pozitív egész számnak kell lennie!")
else:
    # Összeg számítása
    Sn = (n / 2) * (2 * a1 + (n - 1) * d)
    
    # Eredmények kiíratása
    print("\nSzámtani sorozat adatai:")
    print("Első elem (a₁) =", a1)
    print("Differencia (d) =", d)
    print("Elemek száma (n) =", n)
    print("\nAz első", n, "elem összege:")
    print("Sₙ =", round(Sn, 2))
    
    # Bonus: Az első néhány elem kiíratása
    print("\nAz első", min(n, 10), "elem:")
    for i in range(1, min(n, 10) + 1):
        elem = a1 + (i - 1) * d
        print("a" + str(i) + " =", round(elem, 2), end=" | ")
        if i % 5 == 0:
            print()  # Új sor minden 5. elem után

6. Szövegek kezelése

String műveletek és metódusok

String műveletek

A stringek (szövegek) a Pythonban sokféle művelettel kezelhetők. A leggyakoribb műveletek:

string_muveletek.py
# String összefűzés (konkatenáció)

String indexelés és szeletelés

A stringekben a karakterek indexelhetők, és részei kivághatók (szeletelhetők).

Példa: String indexelés

string_indexeles.py
szoveg = "Python"

# Egy karakter elérése
print(szoveg[0])  # P (első karakter)
print(szoveg[2])  # t (harmadik karakter)
print(szoveg[-1]) # n (utolsó karakter)
print(szoveg[-3]) # h (harmadik karakter a végétől)

# String szeletelés (slicing)
print(szoveg[0:2])   # Py (0-tól 2-ig, de a 2 nincs benne)
print(szoveg[2:5])   # tho
print(szoveg[2:])    # thon (2-től a végéig)
print(szoveg[:4])    # Pyth (elejétől 4-ig)
print(szoveg[::2])   # Pto (minden második karakter)

Alapvető string metódusok

A stringeknek számos beépített metódusa van, amelyek segítenek a szöveg kezelésében.

string_metodusok.py
szoveg = "  python alapok  "

# Nagybetűs és kisbetűs konverzió
print(szoveg.upper())      # "  PYTHON ALAPOK  "
print(szoveg.lower())      # "  python alapok  "
print(szoveg.title())      # "  Python Alapok  "

# Whitespace eltávolítás
print(szoveg.strip())      # "python alapok"
print(szoveg.lstrip())     # "python alapok  "
print(szoveg.rstrip())     # "  python alapok"

# Csere és keresés
uj_szoveg = szoveg.replace("python", "JavaScript")
print(uj_szoveg)          # "  JavaScript alapok  "

print("'python' a szövegben:", "python" in szoveg)          # True
print("'alapok' pozíciója:", szoveg.find("alapok"))   # 9

Feladat 6.1: Szövegformázó program

Készíts egy programot, amely bekér egy tetszőleges szöveget, majd:

  1. Kiírja a szöveg hosszát
  2. Nagybetűsíti az egész szöveget
  3. Megfordítja a szöveget
  4. Megkeresi, hányszor fordul elő benne az "a" betű (kis- és nagybetű érzékenyen)
Példa megoldás
# Szöveg bekérése
szoveg = input("Kérlek, adj meg egy szöveget: ")

# 1. Hossz kiírása
print("A szöveg hossza:", len(szoveg), "karakter")

# 2. Nagybetűsítés
print("Nagybetűsen:", szoveg.upper())

# 3. Megfordítás
print("Megfordítva:", szoveg[::-1])

# 4. 'a' betűk számolása
a_szam = szoveg.count('a')
print("Az 'a' betű", a_szam, "alkalommal fordul elő.")

# Bonus: 'a' betűk számolása kis- és nagybetű érzéketlenül
a_szam_osszes = szoveg.lower().count('a')
print("Az 'a' betű (kis/nagybetű érzéketlen):", a_szam_osszes, "alkalommal")

Példa 3: BMI (Testtömeg-index) kalkulátor

Számítsuk ki a testtömeg-indexet és értékeljük az eredményt.

bmi_kalkulator.py
# BMI (Body Mass Index) kalkulátor
print("=== BMI KALKULÁTOR ===\n")

# Adatok bekérése
print("Kérlek, add meg a következő adatokat:")
suly = float(input("Testsúly (kg): "))
magassag = float(input("Magasság (m): "))

# BMI számítás: BMI = súly / (magasság²)
bmi = suly / (magassag ** 2)

# Eredmény kiíratása
print("\n" + "="*40)
print("EREDMÉNYEK")
print("="*40)
print(f"Testsúly: {suly} kg")
print(f"Magasság: {magassag} m")
print(f"BMI: {bmi:.2f}")

# BMI értékelése
print("\nÉrtékelés:")
if bmi < 18.5:
    print("Alulsúly")
    print("Javaslat: Táplálkozz rendszeresen, fogyassz több kalóriát!")
elif bmi < 25:
    print("Normál testsúly")
    print("Kiváló! Tartsd ezt a testsúlyt!")
elif bmi < 30:
    print("Túlsúly")
    print("Javaslat: Törekedj a testsúly csökkentésére!")
else:
    print("Elhízás")
    print("Javaslat: Fordulj orvoshoz vagy táplálkozási tanácsadóhoz!")

Feladat 7.1: Banki kamatszámítás Közepes

Készíts egy programot, amely kiszámítja, mennyi pénzed lesz kamatos kamattal tőkésítve adott futamidő után.

Képlet: Összeg = Kezdőtőke × (1 + Kamatláb/100)Évek

A program kérje be:

  • Kezdőtőkét (Ft)
  • Éves kamatlábat (%)
  • Futamidőt (év)

Írd ki évenként a növekedést!

Példa megoldás
# Kamatos kamat számítása
print("=== KAMATOS KAMAT SZÁMÍTÓ ===\n")

# Adatok bekérése
toke = float(input("Kezdő tőke (Ft): "))
kamatlab = float(input("Éves kamatláb (%): "))
evek = int(input("Futamidő (év): "))

# Fejléc kiírása
print("\n" + "="*60)
print(f"{'Év':<4} {'Év eleji összeg':<20} {'Kamat':<15} {'Év végi összeg':<20}")
print("="*60)

jelenlegi_osszeg = toke

for ev in range(1, evek + 1):
    kamat = jelenlegi_osszeg * (kamatlab / 100)
    uj_osszeg = jelenlegi_osszeg + kamat
    
    print(f"{ev:<4} {jelenlegi_osszeg:>20,.0f} Ft {kamat:>15,.0f} Ft {uj_osszeg:>20,.0f} Ft")
    
    jelenlegi_osszeg = uj_osszeg

# Összegzés
vegosszeg = toke * (1 + kamatlab/100) ** evek
osszkamat = vegosszeg - toke

print("="*60)
print(f"\nÖsszegzés:")
print(f"Kezdő tőke: {toke:,.0f} Ft")
print(f"Futamidő: {evek} év")
print(f"Éves kamatláb: {kamatlab}%")
print(f"Összes kamat: {osszkamat:,.0f} Ft")
print(f"Végső összeg: {vegosszeg:,.0f} Ft")
Feladat 7.2: Geometriai alakzatok számológép Nehéz

Készíts egy programot, amely lehetővé teszi különböző geometriai alakzatok kerületének és területének számítását.

A program kínáljon lehetőséget a következő alakzatok közül választani:

  1. Négyzet
  2. Téglalap
  3. Kör
  4. Háromszög (derékszögű)
  5. Paralelogramma

A program kérje be a szükséges adatokat, majd számítsa ki és írja ki a kerületet és területet.

Példa megoldás
# Geometriai alakzatok számológép
print("=== GEOMETRIAI ALAKZATOK SZÁMOLÓGÉP ===\n")

# Menü megjelenítése
print("Válassz egy alakzatot:")
print("1. Négyzet")
print("2. Téglalap")
print("3. Kör")
print("4. Derékszögű háromszög")
print("5. Paralelogramma\n")

valasztas = input("Add meg a választásod (1-5): ")

# PI értéke
PI = 3.14159

if valasztas == "1":
    # Négyzet
    print("\n=== NÉGYZET ===")
    a = float(input("Add meg az oldal hosszát: "))
    kerulet = 4 * a
    terulet = a ** 2
    
elif valasztas == "2":
    # Téglalap
    print("\n=== TÉGLALAP ===")
    a = float(input("Add meg az 'a' oldal hosszát: "))
    b = float(input("Add meg a 'b' oldal hosszát: "))
    kerulet = 2 * (a + b)
    terulet = a * b
    
elif valasztas == "3":
    # Kör
    print("\n=== KÖR ===")
    r = float(input("Add meg a kör sugarát: "))
    kerulet = 2 * PI * r
    terulet = PI * (r ** 2)
    
elif valasztas == "4":
    # Derékszögű háromszög
    print("\n=== DERÉKSZÖGŰ HÁROMSZÖG ===")
    a = float(input("Add meg az 'a' befogó hosszát: "))
    b = float(input("Add meg a 'b' befogó hosszát: "))
    # Átfogó számítása Pitagorasz-tétellel
    c = (a**2 + b**2) ** 0.5
    kerulet = a + b + c
    terulet = (a * b) / 2
    
elif valasztas == "5":
    # Paralelogramma
    print("\n=== PARALELOGRAMMA ===")
    a = float(input("Add meg az 'a' oldal hosszát: "))
    b = float(input("Add meg a 'b' oldal hosszát: "))
    m = float(input("Add meg az 'a' oldalhoz tartozó magasságot: "))
    kerulet = 2 * (a + b)
    terulet = a * m
    
else:
    print("Érvénytelen választás!")
    kerulet = terulet = 0

# Eredmények kiíratása (ha érvényes választás volt)
if kerulet != 0 or terulet != 0:
    print("\n" + "="*40)
    print("EREDMÉNYEK")
    print("="*40)
    print(f"Kerület: {kerulet:.2f} egység")
    print(f"Terület: {terulet:.2f} négyzetegység")
    print("="*40)
