3. Elágazások és feltételek

3. Grananja i uslovi

A programok döntéseket hoznak feltételek alapján. Erre szolgálnak az if, else if, else és switch szerkezetek.

Programi donose odluke na osnovu uslova. Za to služe if, else if, else i switch strukture.

if (pontszam >= 90) { console.log("Jeles / Odličan"); } else if (pontszam >= 70) { console.log("Jó / Dobar"); } else { console.log("Próbáld újra / Pokušaj ponovo"); }

5. Függvények és rekurzió

5. Funkcije i rekurzija

A függvények újrafelhasználható kódblokkok. Paramétereket fogadhatnak és visszatérési értéket adhatnak. A rekurzió azt jelenti, hogy egy függvény önmagát hívja.

Funkcije su blokovi koda koji se mogu ponovo koristiti. Mogu primati parametre i vraćati vrednost. Rekurzija znači da funkcija poziva samu sebe.

-- Haskell (funkcionális stílus) -- factorial 0 = 1 factorial n = n * factorial (n - 1)

✨ Tipp: A rekurziónak mindig kell egy alapeset (bázis eset), különben végtelen ciklusba kerül.

✨ Savet: Rekurzija uvek mora imati bazni slučaj, inače dolazi do beskonačne petlje.

8. Kivételkezelés és fájlkezelés

8. Obrada izuzetaka i rad sa fajlovima

A programok futás közben hibákba ütközhetnek. A try-catch blokkok segítségével kezelhetjük ezeket. A fájlok olvasása/írása alapvető művelet.

Programi mogu naići na greške tokom izvršavanja. try-catch blokovi služe za njihovu obradu. Čitanje i pisanje fajlova su osnovne operacije.

# Python: kivételkezelés és fájl írás try: with open("diakok.txt", "w") as f: f.write("Név, Jegy\n") except IOError: print("Hiba a fájl írásakor / Greška pri pisanju")

10. Adatbázisok és SQL alapok

10. Baze podataka i SQL osnove

Az adatbázisok strukturált adattárolást tesznek lehetővé. Az SQL nyelvvel lekérdezhetjük, módosíthatjuk az adatokat.

Baze podataka omogućavaju strukturirano skladištenje podataka. SQL jezikom ih pretražujemo i menjamo.

-- SQL alap parancsok SELECT nev, jegy FROM diakok WHERE jegy >= 3; INSERT INTO diakok (nev, jegy) VALUES ('Krisztina', 5); UPDATE diakok SET jegy = 4 WHERE nev = 'Péter';

12. Testiranje i otklanjanje grešaka

A tesztelés biztosítja, hogy a kód helyesen működik. Az egységtesztek (unit test) az apró részeket ellenőrzik. A debuggolás a hibák megtalálásának folyamata.
